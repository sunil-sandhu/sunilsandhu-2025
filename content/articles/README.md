## How to use
1. Proofread each piece (especially any `[VERIFY]` facts and metric phrasing).

3. Where the platform supports it, set `rel=canonical` back to your site if you also host the piece; otherwise keep the in-body link back to sunilsandhu.com.
4. Keep bios/links identical to the brand kit across every placement.
